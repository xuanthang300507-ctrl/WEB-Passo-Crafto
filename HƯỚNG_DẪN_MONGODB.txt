1. CÀI ĐẶT YÊU CẦU
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Node.js (v14+): https://nodejs.org/
✓ MongoDB (v4.4+): https://www.mongodb.com/try/download/community
✓ npm hoặc yarn


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. CÀI ĐẶT MONGODB TRÊN WINDOWS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Bước 1: Tải MongoDB Community Server
   - Truy cập: https://www.mongodb.com/try/download/community
   - Chọn phiên bản Windows MSI (khuyến nghị)

Bước 2: Chạy trình cài đặt (.msi)
   - Làm theo hướng dẫn trên màn hình
   - Chọn "Install MongoDB as a Service" (tùy chọn)

Bước 3: Kiểm tra cài đặt
   - Mở PowerShell và chạy:
     mongo --version
     
Bước 4: Khởi động MongoDB
   - Nếu cài dưới dạng Service: MongoDB sẽ tự chạy
   - Nếu không: chạy mongod.exe từ thư mục cài đặt

Bước 5: Kiểm tra kết nối
   - Mở terminal mới, chạy: mongo
   - Bạn sẽ thấy shell MongoDB


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3. SETUP BACKEND PROJECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Bước 1: Cài đặt dependencies
   cd C:\PassoCrafto
   npm install

Bước 2: Kiểm tra file .env
   - Đã có file .env trong thư mục gốc
   - Mặc định: MONGODB_URI=mongodb://localhost:27017/passo-crafto
   - Thay đổi nếu cần (nếu dùng MongoDB Atlas)

Bước 3: Khởi chạy server
   npm start        (production)
   npm run dev      (development - với auto-reload)

Bước 4: Kiểm tra kết nối
   - Server chạy ở http://localhost:5000
   - Kiểm tra health: GET http://localhost:5000/api/health

4. CẤU TRÚC DỮ LIỆU (SCHEMA)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌─ USER (Profile cá nhân)
│
├─ _id (ObjectId) - ID duy nhất tự động
├─ firstName (string) - Họ *yêu cầu
├─ lastName (string) - Tên *yêu cầu
├─ email (string) - Email *yêu cầu, duy nhất
├─ phone (string) - Số điện thoại
├─ specialization (enum) - Lĩnh vực: 'Software Engineering', 'AI', 'Data Science', 'Finance', 'Other'
├─ bio (string) - Tiểu sử (tối đa 500 ký tự)
├─ skills (array) - Danh sách kỹ năng
├─ avatar (string) - URL ảnh đại diện
├─ socialLinks (object)
│  ├─ linkedin (string)
│  ├─ github (string)
│  ├─ twitter (string)
│  └─ portfolio (string)
├─ teamId (ObjectId) - Tham chiếu Team (nếu có)
├─ role (enum) - Vai trò: 'Leader', 'Member', 'Contributor'
├─ isActive (boolean) - Trạng thái hoạt động (mặc định: true)
├─ createdAt (date) - Ngày tạo (tự động)
└─ updatedAt (date) - Ngày cập nhật (tự động)

┌─ TEAM (Nhóm làm việc)
│
├─ _id (ObjectId) - ID duy nhất tự động
├─ name (string) - Tên team *yêu cầu, duy nhất
├─ description (string) - Mô tả (tối đa 1000 ký tự)
├─ members (array) - Danh sách thành viên
│  └─ { userId, role, joinedAt }
├─ avatar (string) - URL logo team
├─ specialization (enum) - Lĩnh vực: 'Software Engineering', 'AI', 'Data Science', 'Finance', 'Mixed'
├─ socialLinks (object) - Liên kết xã hội
├─ totalMembers (number) - Tổng thành viên
├─ totalAchievements (number) - Tổng thành tích
├─ isActive (boolean) - Trạng thái hoạt động
├─ createdAt (date) - Ngày tạo
└─ updatedAt (date) - Ngày cập nhật

┌─ ACHIEVEMENT (Thành tích)
│
├─ _id (ObjectId) - ID duy nhất tự động
├─ title (string) - Tiêu đề *yêu cầu
├─ description (string) - Mô tả chi tiết *yêu cầu
├─ category (enum) - Loại: 'Award', 'Competition', 'Project', 'Publication', 'Certification', 'Other'
├─ userId (ObjectId) - Người đạt thành tích (có thể null)
├─ teamId (ObjectId) - Team đạt thành tích (có thể null)
├─ contributors (array) - Danh sách người tham gia
│  └─ { userId, role }
├─ badge (string) - URL huy hiệu/chứng chỉ
├─ achievementDate (date) - Ngày đạt thành tích *yêu cầu
├─ location (string) - Địa điểm
├─ organization (string) - Tổ chức
├─ link (string) - Liên kết bằng chứng
├─ priority (enum) - Mức độ: 'Gold', 'Silver', 'Bronze', 'Standard'
├─ views (number) - Số lượt xem
├─ likes (number) - Số lượt thích
├─ createdAt (date) - Ngày tạo
└─ updatedAt (date) - Ngày cập nhật

5. API ENDPOINTS - USERS (Profile cá nhân)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📌 GET /api/users
   - Lấy tất cả người dùng hoạt động
   - Response: { success: true, data: [...] }

📌 GET /api/users/:id
   - Lấy thông tin chi tiết người dùng
   - Params: id = User ID
   - Response: { success: true, data: {...} }

📌 POST /api/users
   - Tạo người dùng mới
   - Body: {
       firstName: "John",
       lastName: "Doe",
       email: "john@example.com",
       phone: "0123456789",
       specialization: "Software Engineering",
       bio: "...",
       skills: ["Python", "JavaScript"],
       avatar: "url...",
       socialLinks: { linkedin: "...", github: "..." }
     }
   - Response: { success: true, data: {...} }

📌 PUT /api/users/:id
   - Cập nhật thông tin người dùng
   - Params: id = User ID
   - Body: { fields_to_update }
   - Response: { success: true, data: {...} }

📌 DELETE /api/users/:id
   - Vô hiệu hóa người dùng (soft delete)
   - Params: id = User ID
   - Response: { success: true, message: "User deactivated", data: {...} }

📌 GET /api/users/specialization/:specialization
   - Lấy người dùng theo lĩnh vực
   - Params: specialization = 'Software Engineering', 'AI', 'Data Science', 'Finance'
   - Response: { success: true, data: [...] }

📌 GET /api/users/team/:teamId
   - Lấy tất cả thành viên của một team
   - Params: teamId = Team ID
   - Response: { success: true, data: [...] }

9. CÁCH SỬ DỤNG VỚI TOOLS (Postman, curl, ...)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

POSTMAN:
1. Tải Postman từ https://www.postman.com/downloads/
2. Tạo một workspace mới
3. Tạo requests theo các endpoint ở trên
4. Set headers: Content-Type: application/json
5. Copy body từ các ví dụ

CURL (Command Line):
curl -X POST http://localhost:5000/api/users \
  -H "Content-Type: application/json" \
  -d '{
    "firstName": "Nguyễn",
    "lastName": "Văn A",
    "email": "nguyena@example.com",
    "specialization": "Software Engineering"
  }'

VS CODE REST CLIENT Extension:
1. Cài: REST Client by Huachao Mao
2. Tạo file .http hoặc .rest
3. Viết requests theo format:
   POST http://localhost:5000/api/users
   Content-Type: application/json
   
   {
     "firstName": "Nguyễn",
     ...
   }

10. QUẢN LÝ DATABASE MONGODB
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MONGODB COMPASS (GUI Tool):
1. Tải: https://www.mongodb.com/try/download/compass
2. Kết nối đến: mongodb://localhost:27017
3. Xem collections, documents, thêm/sửa/xóa dữ liệu
4. Trực quan hóa dữ liệu dễ dàng

MONGO SHELL (CLI):
mongo                          # Kết nối đến MongoDB
> show databases               # Danh sách databases
> use passo-crafto             # Chuyển sang database
> show collections             # Danh sách collections
> db.users.find()              # Xem tất cả users
> db.users.findOne()           # Xem một user
> db.users.find({_id: ObjectId("...")})  # Tìm user theo ID
> db.users.deleteOne({_id: ObjectId("...")})  # Xóa user

DUMP/BACKUP DATABASE:
# Backup toàn bộ database
mongodump --uri mongodb://localhost:27017/passo-crafto --out ./backup

# Restore database
mongorestore --uri mongodb://localhost:27017 ./backup

11. MONGODB ATLAS (Cloud Database)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Nếu muốn dùng MongoDB online (free tier 512MB):

Bước 1: Đăng ký
   - Truy cập: https://www.mongodb.com/cloud/atlas
   - Đăng ký tài khoản miễn phí

Bước 2: Tạo Cluster
   - Chọn Cloud Provider (AWS, Google Cloud, Azure)
   - Chọn Tier: FREE (shared)
   - Chọn khu vực gần nhất

Bước 3: Cấu hình Connection
   - Tạo Database User
   - Lấy Connection String: mongodb+srv://user:pass@cluster.mongodb.net/passo-crafto

Bước 4: Cập nhật .env
   MONGODB_URI=mongodb+srv://user:pass@cluster.mongodb.net/passo-crafto

Bước 5: Khởi chạy lại server
   npm start

12. TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Lỗi: "MongoDB connection failed"
   ✓ Kiểm tra MongoDB daemon đang chạy: mongod --version
   ✓ Khởi động: mongod
   ✓ Kiểm tra port: 27017

❌ Lỗi: "Cannot find module 'mongoose'"
   ✓ Chạy: npm install

❌ Lỗi: "Port 5000 already in use"
   ✓ Thay đổi PORT trong .env
   ✓ Hoặc đóng process đang chạy: netstat -ano | findstr :5000

❌ Lỗi: "Email already exists"
   ✓ Email phải duy nhất
   ✓ Kiểm tra trong MongoDB Compass
   ✓ Xóa duplicate hoặc dùng email khác

❌ Lỗi: "Invalid specialization"
   ✓ Specialization phải là một trong: 
     'Software Engineering', 'AI', 'Data Science', 'Finance', 'Other'

❌ Lỗi: "Team members is not an array"
   ✓ Khi tạo team, không cần members
   ✓ Thêm members sau bằng endpoint POST /teams/:id/members
